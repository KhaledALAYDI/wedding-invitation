# دعوة زفاف خالد وسارة

صفحة ثابتة جاهزة للنشر على GitHub Pages، ولا تحتاج إلى تثبيت حزم أو تشغيل خادم.

## النشر

1. أنشئ مستودعاً جديداً على GitHub وارفع إليه `index.html` و`style.css` و`script.js` و`preview.png` و`precious-memories(chosic.com).mp3`.
2. من إعدادات المستودع، افتح **Pages**. تحت **Build and deployment** اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)` واضغط **Save**.
3. بعد اكتمال النشر، انسخ الرابط الظاهر في صفحة إعدادات Pages وشاركه.

رابط صورة معاينة المشاركة مضبوط على `https://khaledalaydi.github.io/wedding-invitation/`. إذا نشرت الصفحة على عنوان آخر، حدّث رابطَي `og:url` و`og:image` في `index.html`.

العد التنازلي مضبوط على ٢٣ ديسمبر ٢٠٢٦، الساعة السادسة مساءً بتوقيت لبنان. زر الموقع يفتح نتائج البحث عن القاعة في خرائط Google، وليس موقعاً مؤكداً؛ استبدل الرابط في `index.html` برابط القاعة الدقيق قبل المشاركة.

الموسيقى من ملف MP3 الموجود في المجلد. يحاول الموقع تشغيلها تلقائياً وتكرارها، لكن بعض المتصفحات تمنع التشغيل بالصوت حتى يضغط الزائر زر التشغيل. تأكد من أن لديك حق استخدام الموسيقى ومشاركتها قبل نشر الدعوة.
